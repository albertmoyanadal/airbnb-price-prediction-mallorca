## Objectiu

Preparar les dades crues (`listings.csv`) per a la fase de modelització mitjançant un procés de neteja estructurat per etapes. El procés es realitza en diferents scripts.

## Etapa 1: Eliminació de variables

**Script**: `remove_variables.py`  
**Entrada**: `listings.csv` + `data_summary.xlsx`  
**Sortida**: `listings_step1.csv`

### Descripció
Elimina les variables que no són rellevants per a la predicció de preus segons el criteri definit a `data_summary.xlsx` (columna `Mantenir = Sí`).

### Variables eliminades (exemples)
- Variables identificadores: `listing_url`, `scrape_id`, `last_scraped`, `source`
- Variables de text: `name`, `description`, `neighborhood_overview`
- Variables redundants: `host_total_listings_count`, `calculated_host_listings_count_*`
- Variables amb 100% nuls: `neighbourhood_group_cleansed`, `calendar_updated`

### Resultats
- **Columnes inicials**: 79
- **Columnes finals**: 41
- **Reducció**: 38 columnes eliminades

### Decisions preses
- Es mantenen variables clau per a la predicció:
  - Preu (`price`)
  - Característiques de la propietat (`accommodates`, `bathrooms`, `bedrooms`, `beds`)
  - Ubicació (`latitude`, `longitude`, `neighbourhood_cleansed`)
  - Ressenyes i puntuacions (`review_scores_*`)
  - Host (`host_is_superhost`, `host_listings_count`, etc.)
  - Disponibilitat (`availability_30`, `availability_365`)



## Etapa 2: Canvi de tipus de variables

**Script**: `change_types.py`  
**Entrada**: `listings_step1.csv` + `data_summary.xlsx`  
**Sortida**: `listings_step2.csv`

### Descripció
Converteix les variables al tipus de dada adequat segons les indicacions de `data_summary.xlsx` (columna `Canviar tipus`).

### Funcions de conversió implementades

| Funció | Descripció | Exemple |
|--------|------------|---------|
| `to_bool` | Converteix 't'/'f' a booleà | `'t'` → `True` |
| `to_float_percent` | Converteix percentatges a escala 0-1 | `'100%'` → `1.0` |
| `to_price` | Converteix preu amb `$` a float | `'$164.00'` → `164.0` |

### Variables convertides

| Variable | Tipus original | Tipus final | Notes |
|----------|---------------|-------------|-------|
| `host_since` | `str` | `datetime64` | Data d'alta de l'host |
| `host_response_rate` | `str` | `float64` | `'95%'` → `0.95` |
| `host_acceptance_rate` | `str` | `float64` | `'100%'` → `1.0` |
| `host_is_superhost` | `str` | `boolean` | `'t'` → `True` |
| `host_has_profile_pic` | `str` | `boolean` | `'f'` → `False` |
| `host_identity_verified` | `str` | `boolean` | `'t'` → `True` |
| `bathrooms` | `float64` | `float64` | Es manté `float` (pot ser 1.5) |
| `bedrooms` | `float64` | `Int64` | Converteix a enter (accepta NaN) |
| `beds` | `float64` | `Int64` | Converteix a enter (accepta NaN) |
| `price` | `str` | `float64` | `'$164.00'` → `164.0` |
| `has_availability` | `str` | `boolean` | `'t'` → `True` |
| `first_review` | `str` | `datetime64` | Data de la primera ressenya |
| `last_review` | `str` | `datetime64` | Data de l'última ressenya |
| `instant_bookable` | `str` | `boolean` | `'t'` → `True` |
| `license` | `str` | `str` | Es manté com a string (per tractar després) |

### Resultats
- **Variables convertides**: 13
- **Variables pendents** (Mirar categories): 6

## Etapa 4: Transformació de categories

**Script**: `transform_categories.py`  
**Entrada**: `listings_step2.csv`  
**Sortida**: `listings_step3.csv`

### Descripció
Transforma les variables categòriques en variables numèriques mitjançant one-hot encoding i agrupacions.

### 4.1 `host_verifications` → One-hot encoding

| Variable original | Noves variables | Valors |
|-------------------|-----------------|--------|
| `host_verifications` | `verif_email` | `True`/`False` |
| | `verif_phone` | `True`/`False` |
| | `verif_work_email` | `True`/`False` |

**Exemple de conversió**:
- `['email', 'phone']` → `verif_email=True`, `verif_phone=True`, `verif_work_email=False`

### 4.2 `property_type` → Agrupació + One-hot encoding

**Funció d'agrupació**: `get_property_group()`

| Grup | Descripció | Exemples |
|------|------------|----------|
| `villa` | Vil·les | `Entire villa` |
| `house` | Cases | `Entire home`, `Entire cottage`, `Entire chalet` |
| `apartment` | Apartaments | `Entire rental unit`, `Entire condo`, `Entire loft` |
| `private_room` | Habitació privada | `Private room in villa`, `Private room in home` |
| `shared_room` | Habitació compartida | `Shared room in hotel` |
| `hotel` | Hotels | `Room in hotel`, `Room in boutique hotel` |
| `other` | Altres | `Camper/RV`, `Boat`, `Castle`, `Tiny home` |

**Noves variables**:
- `prop_villa`, `prop_house`, `prop_apartment`, `prop_private_room`, `prop_shared_room`, `prop_hotel`, `prop_other`

## Decisions metodològiques destacades

1. **Eliminació de variables amb >50% nuls**: Per evitar soroll i reduir dimensionalitat.
2. **One-hot encoding vs agrupació**: 
   - `room_type` (4 categories) → one-hot encoding directe
   - `property_type` (59 categories) → agrupació en 7 grups + one-hot
   - `amenities` (14.327 combinacions) → extracció de les 10 més freqüents
3. **Tractament de nuls en review scores**: 
   - Creació de variable de control `has_reviews`
   - Ompliment amb mediana per no perdre el 19% de les dades
4. **Eliminació selectiva de files**: 
   - Variables crítiques amb pocs nuls → eliminació de files
   - Review scores amb molts nuls → ompliment amb mediana
